# 项目状态与功能清单

## 当前阶段

当前仓库处于 **v0.1 Demo → v0.2 功能完善阶段**。

第一阶段目标不是追求界面完全复刻，而是优先打通并稳定下面这条真实发布链路：

```text
创建实例
→ 扫码登录 QQ
→ 持久化登录态
→ 添加腾讯频道
→ 创建发布任务
→ Playwright 打开频道
→ 上传素材
→ 填写内容
→ 点击发表
→ 检测结果
→ 保存任务状态和日志
```

---

## 3. Chromium 登录态持久化

已实现：

- Playwright Chromium。
- `launchPersistentContext`。
- 每个实例独立 `profiles/<instanceId>`。
- 打开 `https://pd.qq.com/` 登录页面。
- 浏览器关闭后保留 Cookie / LocalStorage / IndexedDB 等浏览器 Profile 数据。

状态：**代码已实现，仍需要在真实腾讯频道环境中持续验证长期稳定性**。

待完善：

- 自动识别“已登录 / 未登录 / 登录失效”。
- 在软件顶部实时显示账号登录状态。
- 登录失效后自动暂停任务。
- 重新登录后继续未完成任务。

## 6. Playwright 自动发布基础链路

已实现：

- 打开目标频道 URL。
- 根据配置读取页面元素选择器。
- 点击 / 定位发帖区域的基础逻辑。
- 设置文件上传 input。
- 填写标题 / 正文的基础逻辑。
- 点击发布按钮。
- 记录成功或失败。
- 单个目标频道失败不影响数据库保存错误信息。

状态：**已有骨架，但真实页面选择器和发布状态判断仍在继续适配**。

当前重点：

- 用户已经提供真实 `pd.qq.com` 页面 HTML。
- 页面确认使用 ProseMirror 编辑器。
- 旧版将正文按 `textarea` 处理的方案需要调整。
- “发布按钮 / 上传 input / 编辑区域 / 上传完成状态”需要基于真实 DOM 继续校准。
