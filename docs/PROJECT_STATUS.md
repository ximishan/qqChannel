# 项目状态与功能清单

## 当前阶段

当前分支：`codex/multi-account-dom`

当前重点是稳定下面这一条唯一主流程：

```text
实例独立窗口
→ QQ 独立登录态
→ 自动同步频道
→ 创建发布任务
→ 每实例独立队列
→ 油猴 DOM 发帖
→ 新帖确认
→ 自动评论
→ 状态 / 日志 / 截图
```

## 已完成

### 1. 多实例窗口

- 一个实例一个业务窗口。
- 每个实例独立 WebContentsView。
- 每个实例独立 `persist:qq-channel-instance-<id>`。
- 关闭的实例可通过顶部实例下拉框重新打开/聚焦。
- 当前窗口不会因为选择其他实例而串号。

### 2. QQ 登录

- 每实例独立持久化登录状态。
- 每实例独立本地加密登录备份。
- 点击“登录QQ”自动打开当前实例内置浏览器。
- 自动尝试触发 QQ 扫码二维码。
- 扫码后自动轮询登录状态。
- 避免普通频道页面 DOM 短暂变化把已登录状态误清空。

### 3. 频道自动同步

- 登录成功自动读取频道。
- 自动新增缺失频道。
- 自动更新已有频道。
- 当前打开频道与侧边栏频道合并去重。
- 逐频道切换时必须确认 URL 真正变化后才记录。
- 发布任务运行期间自动延后频道同步，避免争抢同一个 QQ 页面。
- 保留“重新同步”作为异常重试入口。

### 4. 发布任务

支持：

- 纯文本
- 图片
- 单个视频
- 视频目录批量

统一字段：

- 任务名称：仅本地使用。
- 内容：发布正文。
- 评论：发布成功后自动评论。
- 开始时间。
- 随机间隔。
- 目标频道。

视频目录批量已合并到“新建发布任务”，内容和评论均支持 `{filename}`。

### 5. 唯一发布 / 评论主链

当前唯一执行链：

```text
publishing-data-support
→ userscript-dom-publishing-support
→ publish-runtime-feedback-support
```

其中：

- 数据层负责正文/评论分离、帖子已发布状态和评论状态。
- `userscript-dom-publishing-support` 负责真实发帖与评论。
- runtime feedback 只负责 Electron 本地文件适配和实时步骤提示。

已删除旧：

- CLI 发布器
- selector 发布器兼容补丁
- 旧评论补丁
- 发帖展开 fallback
- 单账号发布模式
- 账号工作区兼容层

### 6. 油猴 DOM 发布流程

当前以用户提供并实测成功的 Tampermonkey 脚本为标准。

发帖：

```text
打开发布编辑器
→ 写入正文 ProseMirror
→ 设置图片 / 视频
→ 等待媒体预览
→ 等待 image-mask 消失
→ 等待发表按钮可用
→ 点击发表
→ 等待新的 .msgBox[data-index]
→ 保存 /post/B_xxx
```

评论：

```text
进入 /post/B_xxx
→ 点击 .bottom-comment-input .bottom-input
→ 等待 .comment-editor-container .ProseMirror
→ 写入评论
→ 等发送按钮可用
→ 点击发送
→ 确认评论结果
```

发布算法不再叠加另一套旧选择器逻辑。

### 7. 防重复发布

任务目标保存：

- `post_published`
- `post_url`
- `comment_status`

帖子已经确认发布但评论失败时，后续只重试评论，不重复发布帖子。

### 8. 发布队列

- 每实例独立 worker。
- 实例之间可并行。
- 同一实例内串行。
- 启动 / 暂停 / 继续 / 停止。
- 随机任务间隔。
- 同一任务目标频道间隔。
- 登录失效暂停。
- 异常退出后 `running` 状态恢复。
- 实时显示当前任务和发布阶段。

### 9. UI 清理

已经真正删除而不是继续隐藏：

- 独立“批量视频目录”按钮 / 弹窗。
- 发帖元素定位面板。
- 选择器测试面板。
- 旧批量视频 Renderer。
- 旧设置隐藏 shim。
- 旧单账号 UI。
- 旧工作区 UI。
- 旧术语和任务筛选 shim。

设置页目前只保留发布运行参数与评论默认值。

### 10. 测试

- 已删除 CLI 架构测试。
- `npm test` 改为当前发布数据模型测试。
- `npm run test:electron` 改为检查当前多实例 partition 与油猴 DOM 发布链安装状态。

## 当前数据库

主要表：

```text
instances
channels
tasks
task_targets
settings
logs
```

历史数据库中可能仍有 `selector_configs` 等兼容结构。当前油猴发布主链不依赖设置页选择器 UI。

## 维护规则

1. 不再恢复 CLI 发布器。
2. 不再恢复另一套 selector 发布算法。
3. QQ 发布问题先对照用户已经跑通的油猴脚本。
4. 同实例发布时禁止其他自动化逻辑切换频道页面。
5. 新功能优先直接集成到现有入口，不新增重复入口。
6. 无引用的兼容层应删除，不继续长期保留隐藏代码。
