技术栈：

- Electron
- Electron WebContentsView 内置浏览器
- SQLite (`better-sqlite3`)

## 当前已经实现

### 桌面与数据层

- Electron 主进程 / Renderer / Preload / IPC。
- SQLite 本地数据库。
- 实例创建、切换、改名与删除；一个实例对应一个独立登录的 QQ 账号。
- 一个实例可分配多个频道，不同实例使用互不共享的 Chromium 登录会话。
- 新增频道时可在表单中明确选择“所属实例”，保存后自动切换并显示该实例的频道。
- QQ 登录态按实例持久化；退出或删除实例只清理该实例，不影响其他实例。
- 登录状态检测。
- 频道手工添加 / 删除。
- 多频道任务模型。
- 纯文本、单张图片和单个视频任务。
- 日志。

### 真实腾讯频道页面适配

已根据真实 `pd.qq.com` 页面 HTML 调整：

- ProseMirror 评论编辑器。
- `input[type=file]` 图片 / 视频上传。
- 等待图片 / 视频上传进度真正完成，避免过早点击发表。
- 等待“发表”按钮从 disabled 变为 enabled。
- 点击“发表”。
- 成功提示 / 编辑器清空双重 DOM 检测。
- 页面错误提示检测。
- 登录失效检测。
- 失败自动截图。
- 单频道失败自动重试。
- 只重新执行失败目标，不重复已成功频道。

### 发布队列

- 发布过程始终停留在“发布任务”页，内置浏览器不会覆盖任务列表。
- 创建任务时可在工具内多选目标频道；执行前会再次列出并确认频道。
- 同一任务的多个频道按顺序逐个发布，并在任务列表显示每个频道的状态。
- 每个频道发布结束后实时显示成功或失败；整条任务完成后自动回到任务列表。
- 任务列表分页，可选择每页 10、20 或 50 条，并支持全选当前页、跨页保留选择。
- 可批量删除选中的成功、失败或待发布任务；正在发布的任务会受到保护，不影响频道中已经发布的内容。
- 每条任务可单独设置开始时间及完成后的随机间隔。
- 每实例独立发布 worker。
- 可一键启动或停止全部实例，各实例并行、实例内任务串行。
- 启动发布。
- 暂停。
- 继续。
- 停止。
- 顺序执行 pending 任务。
- 全局随机任务间隔。
- GUI 下一条倒计时。
- 软件异常退出后将遗留 `running` 恢复为 `pending`。
- 登录失效时自动暂停队列，并保留未完成任务。

### 批量视频目录 v0.3.1

- 选择本地视频目录。
- 自动识别 `MP4 / MOV / MKV / WEBM / AVI / WMV`。
- 按文件名自然排序。
- 一个视频自动创建一条任务。
- 一次选择多个目标频道。
- 支持统一评论。
- 评论支持 `{filename}` 占位符。
- 创建前显示识别到的视频数量和文件预览。

## 运行参数

设置页当前支持：

- 失败重试次数。
- 上传等待超时。
- 发布结果确认超时。
- 随机最小间隔。
- 随机最大间隔。
- 同一任务的频道间隔（默认 70 秒，用于多频道顺序发布）。
- 失败截图开关。
- 所有关键 DOM 选择器。

选择器支持**一项多行候选值**，会按顺序自动降级。

## 安装

```bash
npm install
npm start
```

Windows 下也可以运行：

```text
start-demo.bat
```

## Windows 内置浏览器版本

项目直接使用 Electron 自带 Chromium，并以 WebContentsView 嵌入主界面，不依赖客户电脑安装 Google Chrome 或 Microsoft Edge，也不会再打开独立的 Chrome 窗口。

“内置浏览器”仅用于 QQ 登录、浏览频道及查看已经发布的内容。频道选择、发布确认、执行进度和结果都在工具的“发布任务”页完成。

生成 Windows 便携版：

```bash
npm run build:win
```

产物位于 `dist/`。Electron 运行时已经包含 Chromium；账号会话、加密登录备份和数据库仍保存在当前 Windows 用户的 Electron `userData` 目录，不会写入程序安装目录。

## 推荐测试流程

1. 启动软件。
2. 创建或选择实例，并向实例添加一个或多个频道。
3. 点击“登录QQ”，程序会切换到该实例的“内置浏览器”页，在软件窗口内完成登录。
4. 点击“检测登录”，确认顶部显示已登录账号。
5. 在“频道管理”中同步当前实例的频道，或手动添加一个 `https://pd.qq.com/g/...` 频道。
6. 创建一条纯文本、单图片或单视频的单频道测试任务。
7. 先使用“执行选中任务”验证真实发帖链路。
8. 查看日志以及失败截图。
9. 单条链路稳定后，再用“批量视频目录”创建多条任务。
10. 设置随机间隔，点击“启动发布”测试队列。
