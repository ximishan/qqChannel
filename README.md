# 腾讯频道批量发布工具

技术栈：**Electron + WebContentsView + SQLite（better-sqlite3）**

当前开发分支：`codex/multi-account-dom`

## 当前架构

- 一个实例对应一个独立窗口、一个独立 QQ 登录会话和一个独立发布队列。
- 每个实例使用独立的 Chromium persistent partition：`persist:qq-channel-instance-<id>`。
- QQ 登录成功后自动读取并导入当前账号频道，不需要手工添加或勾选导入。
- 发布任务支持：纯文本、图片、单个视频、视频目录批量。
- 帖子正文与发布后评论独立保存。
- 视频目录批量已经合并进“新建发布任务”，不再有独立批量入口。
- 发帖与评论只有一条执行主链：用户已在 Tampermonkey 中实测通过的 QQ 频道 DOM 流程。
- 旧 CLI 发布器、旧 selector 发布器、旧评论补丁和单账号模式已经从当前分支移除。

## 发布流程

```text
实例窗口
→ 检查当前实例 QQ 登录状态
→ 打开目标频道
→ 展开发帖编辑器
→ 写入正文
→ 注入图片 / 视频文件
→ 按油猴脚本逻辑等待媒体预览和处理完成
→ 等待“发表”按钮可用
→ 点击发表
→ 通过新的 .msgBox[data-index] 确认新帖子
→ 保存 /post/B_xxx 地址
→ 如有评论则进入详情页
→ 展开评论 ProseMirror
→ 发送评论并确认评论结果
→ 保存任务状态
```

发布过程中会暂停当前实例的频道自动同步，避免同步器点击左侧频道干扰发帖页面。

## 实例与登录

每个实例独立保存：

- QQ Cookie / Web Storage / IndexedDB
- Chromium persistent session
- 本地加密登录备份
- 频道
- 发布任务
- 队列状态

软件启动后会为已有实例分别打开独立窗口。顶部实例下拉框只作为“窗口导航器”：选择另一个实例会打开或聚焦它自己的窗口，不会把当前窗口切换成别的账号。

点击“登录QQ”后会自动打开当前实例的 QQ 登录页并尝试直接弹出扫码二维码；扫码成功后自动检测登录并同步频道。

## 频道管理

频道管理以自动同步为主：

```text
QQ 已登录
→ 自动采集当前账号频道
→ 新频道自动新增
→ 已有频道自动更新
→ 本地频道列表刷新
```

“重新同步”仅作为异常情况下的手动重试入口。

## 发布任务

“新建发布任务”支持：

- 纯文本
- 图片
- 视频 → 单个视频
- 视频 → 视频目录批量

字段：

- 任务名称：仅本地识别，不发布到 QQ。
- 内容：真正发布到 QQ 频道的正文。
- 评论：帖子发布成功后自动发送的评论。
- 开始时间。
- 随机任务间隔。
- 目标频道。

视频目录批量模式中，“内容”和“评论”均支持 `{filename}`，会替换为当前视频的不带扩展名文件名。

## 队列

- 每实例独立 worker。
- 实例之间可并行。
- 同一实例内串行执行，避免多个任务争抢同一个 QQ 页面。
- 支持启动、暂停、继续、停止。
- 失败目标可重试。
- 已经确认发帖成功、但评论失败的目标会保存 `post_published / post_url`，重试时只补评论，不重复发帖。
- 失败可自动截图。
- 异常退出后遗留的 `running` 状态会恢复为待处理状态。

## 设置

当前设置页只保留用户真正需要的运行参数：

- 失败重试次数
- 上传等待超时
- 发布结果确认超时
- 任务最小 / 最大随机间隔
- 同一任务频道间隔
- 失败自动截图
- 评论区默认值

“发帖元素定位”和“选择器测试”已经从 UI 和 Renderer IPC 中移除。当前发布器以经过验证的油猴 DOM 逻辑为唯一标准，不再允许旧 selector 发布器参与执行。

数据库为了兼容历史安装仍可保留旧字段/表结构，不能据此判断旧发布器仍在运行。

## 安装与启动

```bash
npm install
npm start
```

Windows 也可以运行：

```text
start-demo.bat
```

生成 Windows 便携版：

```bash
npm run build:win
```

产物位于 `dist/`。

## 测试

普通数据层测试：

```bash
npm test
```

Electron 基础 smoke：

```bash
npm run test:electron
```

真实 QQ 发帖仍必须在本机已登录的真实 `pd.qq.com` 环境中验收。

推荐顺序：

1. 登录一个测试实例。
2. 确认频道自动同步数量正确。
3. 创建 1 条“图片 + 内容 + 评论”任务。
4. 执行选中任务并观察实时步骤日志。
5. 再测试视频与视频目录批量。
6. 最后开启队列连续发布。


## 当前原则

发布相关代码遵循一条规则：**不重新设计已经验证成功的油猴发布算法，只做 Electron、本地文件、多实例、SQLite、任务队列和 UI 适配。**
